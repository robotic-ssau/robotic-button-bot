# Бот клуба Robotic
## 📝 Описание

Этот проект — Telegram и VK бот для робототехнического клуба **[ROBOTIC](https://vk.com/robotic_samara)** Самарского университета.

### Зачем он нужен?
Раньше нам постоянно писали в личные сообщения: *"Открыта ли лаборатория?"* и *"Можно ли прийти?"*. Мы делегировали эти вопросы боту!

### 🛠️ Основные функции:
- 📡 Отвечает участникам, открыта ли лаборатория
- 🔧 Позволяет совету клуба управлять состоянием лаборатории
- 🔄 Синхронизируется с [сервисом управления состоянием](https://github.com/Sapdotten/laba_back)

### Как управлять:
Состояние лаборатории можно изменить:
- Через Telegram или VK бота (для совета клуба)
- Через физическую кнопку в коридоре лаборатории


### Планируемые улучшения:
- [ ] Уведомления об открытии лаборатории для ждущих пользователей

## 🚀 Настройка и запуск
Перед запуском необходимо настроить переменные окружения в `/.docker/.env`:

| Название переменной  | Тип   | По умолчанию        | Описание                                         |
|----------------------|-------|---------------------|--------------------------------------------------|
| COMPOSE_PROJECT_NAME | str   |                     | Имя docker-compose проекта                       |
| BACK_URL             | str   |                     | адрес сервиса управления состоянием лабы         |
| TG_BOT_TOKEN         | str   |                     | токен доступа к telegram-боту                    |
| VK_BOT_TOKEN         | str   |                     | токен доступа к vk-боту                          |
| COUNCIL_CSV          | path  | `data/council.csv`  | файл со списком советовцев                       |
| LOCALE               | str   | `ru`                | файл текстов `src/i18n/locales/<LOCALE>.json`    |
| LOG_DIR              | path  | `logs`              | папка для логов                                  |
| LOG_LEVEL            | str   | `INFO`              | уровень логирования (`DEBUG` — подробнее)        |
| LOG_RETENTION_DAYS   | int   | `30`                | сколько дней хранить логи (`0` — хранить все)    |
| LAB_API_TIMEOUT      | float | `5`                 | таймаут запросов к сервису лабы, секунды         |
| TZ                   | str   | `Europe/Samara`     | часовой пояс (влияет на смену файла логов)       |

Сборка и запуск из корня проекта:
```bash
docker-compose -f ./.docker/docker-compose.yml build
docker-compose -f ./.docker/docker-compose.yml up -d
```

Локальный запуск (из корня проекта):
```bash
python -m src.telegram.entry
python -m src.vk.entry
```

## 👥 Список советовцев
Хранится в `data/council.csv` (папка `data` подключена к контейнерам как volume):

```csv
surname,vk_id,tg_id,is_admin
Иванов,123456789,987654321,1
Петров,,555555555,0
```

- `vk_id` / `tg_id` — числовые id; можно оставить пустым, если аккаунта на платформе нет.
- `is_admin` — `1`/`0` (также понимаются `да`/`нет`, `true`/`false`).
- Все из списка могут открывать и закрывать лабораторию; админы ещё и управляют списком.
- Файл можно править руками (подойдёт и разделитель `;` из Excel): боты подхватят
  изменения без перезапуска.

Админы управляют списком прямо в боте кнопкой **👥 Советовцы**: просмотр, добавление,
изменение и удаление. Данные вводятся одной строкой: `Фамилия; VK id; TG id; да/нет`.
Последнего админа удалить или лишить прав нельзя.

## 🌐 Тексты бота
Все ответы и подписи кнопок лежат в `src/i18n/locales/ru.json`. Чтобы поменять текст,
достаточно отредактировать этот файл и перезапустить бота.

## 📜 Логи
Каждый бот пишет логи в консоль и в файл `logs/<бот>_<ГГГГ-ММ-ДД>.log`
(например, `logs/telegram_2026-10-15.log`); в полночь начинается новый файл.
В логах: входящие сообщения и ответы (с платформой, id и фамилией советовца),
запросы к сервису лабы с временем ответа, кто и когда открыл/закрыл лабораторию,
все изменения списка советовцев (было/стало), отказы в доступе и ошибки с трейсбеком.

----------------------|-----|-----------------------------------------|
| COMPOSE_PROJECT_NAME | str | Имя docker-compose проекта              | 
| BACK_URL             | str | адрес сервиса управления состоянием лабы | 
| TG_BOT_TOKEN         | str | токен доступа к telegram-боту           | 
| VK_BOT_TOKEN         | str | токен доступа к vk-боту                 | 

Сборка и запуск из корня проекта:
```bash
docker-compose -f ./.docker/docker-compose.yml build
docker-compose -f ./.docker/docker-compose.yml up -d
```
